# 🎮 Simon Says Game

A browser-based implementation of the classic **Simon Says** memory game built with vanilla HTML, CSS, and JavaScript.

## 🕹️ Demo

Press any key to start → watch the color sequence → repeat it by clicking the buttons. Each round adds one more step!

## 🚀 Features

- 4-color button grid (Red, Yellow, Green, Purple)
- Increasing difficulty — sequence grows each level
- Visual flash feedback for both game and user input
- Game Over screen with your score
- Red background flash on wrong input
- Fully reset and restartable

## 🛠️ Tech Stack

| HTML5 | Game structure & layout |
| CSS3 | Styling, colors, flash animations |

## 🎯 How to Play

1. Open `index.html` in your browser
2. **Press any key** to start the game
3. Watch the sequence of colors that flash
4. **Click the buttons** in the same order
5. Each correct round adds a new color to the sequence
6. One wrong click = **Game Over**!
7. Press any key again to restart

## ⚙️ Setup & Run Locally

```bash
# Clone the repository
git clone https://github.com/ritesh01-hub/Simon-Says-Game.git

# Navigate into the project
cd Simon-Says-Game

# Open in browser (just double-click index.html, or use Live Server in VS Code)
```
